A deep learning–based computer vision system for detecting plant diseases from leaf images. This project applies state-of-the-art CNN architectures to classify healthy vs. 
diseased leaves, supporting early intervention in the agriculture industry.
Features:
1. Automatic detection of plant diseases from leaf images
2. Multiple CNN architectures: VGG16, ResNet50, EfficientNetB0, InceptionV3
3. Training, validation, and testing pipeline
4. Image preprocessing (resizing, normalization, augmentation)
5. Performance comparison across models
6. Confusion matrix, accuracy graphs, and evaluation metrics
7. Easily deployable for mobile/IoT/agricultural use cases
